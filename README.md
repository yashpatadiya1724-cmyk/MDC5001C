# Combinatorics & Discrete Math: MDC5001C

Interactive learning platform, exam practice centre, and mathematics game zone for **Foundation of Mathematics (Course Code: MDC5001C)** - Unit 1: *Introduction to Combinatorics and Its Applications* (Silver Oak College of Computer Application).

## 🚀 Features

- **Learn & Formulas**: Comprehensive topic-wise guides, step-by-step solutions, interactive formula flashcards, and quick revision drawer.
- **Exam Centre**: Simulated practice tests with customizable timers, instant step hints, and detailed result analytics.
- **Math Games**: 10 interactive mathematics puzzle games covering permutations, combinations, Pigeonhole Principle, derangements, inclusion-exclusion, and recurrence relations.
- **Dark/Light Mode**: Full theme customization with persistent storage.

## 🛠️ Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to `http://localhost:3000`.

## 📦 Build for Production

```bash
npm run build
npm run preview
```
